## 🌍 Overview

**Flightless Falconry** is an original, community-driven companion environment built around eight beloved *OpenPigeon* titles. Rather than treating each game as an isolated island, this toolkit braids them together into a single, cohesive workshop where players can shape their experience with **thirty-six distinct trainer toggles**, each one tuned like a reed in a woodwind — subtle, purposeful, and musical in combination.

Where other projects shout, Flightless Falconry whispers. It assumes the player is curious, patient, and mildly mischievous in the healthiest possible sense. The entire philosophy rests on one metaphor: a falconer does not force the bird; the falconer simply arranges the sky so that the bird chooses the path it already wanted.

This repository is the home of that arrangement.

## 🧭 What You Will Find Here

Flightless Falconry is organized as a set of independent but interoperable modules. Each module exposes a small surface area — usually a single toggle or a small cluster — so that you can compose your own experience without ever feeling obligated to accept the whole buffet.

- **Deterministic behaviour toggles** — make certain in-game events repeatable.
- **Quality-of-life switches** — reduce friction that has nothing to do with the joy of play.
- **Visual comfort options** — adjust the tempo and tone of what you see.
- **Accessibility-oriented adjustments** — widen the doorway for more players.
- **Session shaping utilities** — pause, snapshot, resume, and rewind your flow.
- **Experimental sandboxes** — clearly fenced off, clearly labeled.

## 🧠 Why Another Toolkit?

Because the pigeon world deserves a carpenter's patience, not a demolition crew's enthusiasm. Flightless Falconry exists to prove that a toolkit can be expressive without being exhausting, deep without being cryptic, and playful without ever crossing the line into recklessness. The project is deliberately scoped so that a single thoughtful maintainer could, in principle, explain every line to a curious newcomer over one long evening.

## 📦 Getting Started (Conceptual)

Flightless Falconry does not ask you to memorize command-line incantations. The onboarding flow is meant to feel like opening a well-organized toolbox: everything has a drawer, every drawer has a label, and every label has a picture beside it.

1. Visit the releases area of the repository and locate the build appropriate to your operating system.
2. Unpack the archive into a folder you will remember.
3. Launch the companion application and follow the guided first-run wizard.
4. Pick one game from the adapter list and enable a single toggle as an experiment.
5. Watch how the game responds, then expand your configuration one toggle at a time.

There is no rush. The pigeon does not care if you finish today.

## 🧪 Toggle Philosophy

Toggles are not switches for winning; they are dials for shaping. A toggle that makes one player's evening cozier might make another player's evening noisier. Flightless Falconry respects this. Every toggle ships with a short, honest description of what it does, what it does not do, and who might find it delightful.

A few example toggle *categories*, described in the project's own vocabulary:

- **Cadence Toggles** — adjust the rhythm at which events occur.
- **Visibility Toggles** — change what is emphasized on screen.
- **Assist Toggles** — gently widen the timing windows a player has to act.
- **Narrative Toggles** — surface or hide optional story banners.
- **Snapshot Toggles** — capture a moment so that it can be revisited.
- **Sandbox Toggles** — temporarily relax a rule for experimentation.

## 🧬 Architecture At A Glance

The toolkit is divided into a thin shell and a set of independent adapters. The shell handles presentation, configuration, and localization; the adapters translate abstract toggles into title-specific behaviour. Communication between the two happens through a small, well-documented contract so that adding a ninth title someday is a matter of writing one new adapter rather than rewriting the world.

- **Shell** — user interface, theming, configuration storage, localization
- **Adapters** — one per supported title, each small and self-contained
- **Toggle Registry** — the canonical list of thirty-six toggles
- **Sandbox Host** — an isolated environment for safe experimentation
- **Telemetry (opt-in)** — anonymous diagnostics that help improve stability
